# C4_Max — Telegram-бот по War Thunder Mobile

Бот-помощник с базой знаний по технике (наземная техника, авиация, корабли,
подлодки) и справочником ТТХ, новостями с wtmobile.com, викториной, антиспамом,
админ-панелью в Telegram и веб-админкой.

## Запуск на новом хостинге

1. Скопировать `.env.example` в `.env` (или вписать те же переменные в панели
   хостинга — раздел «Config Vars» / «Переменные окружения»).
2. Заполнить как минимум `TELEGRAM_TOKEN` и `GEMINI_API_KEY`.
3. Установить зависимости:

   ```
   pip install -r requirements.txt
   ```

4. Запустить:

   ```
   python main.py
   ```

Больше ничего настраивать не нужно. При первом запуске `history.db`
разворачивается из заготовки `seed.db` (она лежит в репозитории) — бот сразу
стартует с промптами, настройками и персоналом. Нет заготовки — создаётся
пустая база. Статьи базы знаний переносятся отдельно — см. ниже.

## Что НЕ хранится в репозитории

| Файл | Почему |
|---|---|
| `.env` | живые ключи и токены |
| `history.db` | переписка реальных пользователей |
| `backups/` | ночные копии той же базы — те же живые данные |
| `knowledge/` | статьи базы знаний и указатель поиска: папка живёт на сервере, запасная копия статей каждую ночь приходит владельцу архивом |
| `.build` | метка сборки: какой коммит лежит именно на этой машине |
| `logs/`, `watchdog.log` | мусор времени выполнения |

При переезде на новый хостинг эти файлы переносятся отдельно, вручную.

## Структура

| Папка / файл | Что внутри |
|---|---|
| `main.py` | точка входа, сборка приложения |
| `bot.py` | запасная точка входа для хостингов, которые ищут `bot.py` |
| `config.py` | все настройки и переменные окружения |
| `jobs/` | фоновые задачи: новости, отчёты, ночные копии, вопрос дня, самообновление |
| `handlers/` | обработка команд и сообщений, админ-панель |
| `services/` | модели, RAG, парсер новостей, антиспам, роли |
| `database/` | база: переписка, настройки, журналы, викторина, расходы |
| `web/` | веб-админка — сайт внутри процесса бота |
| `knowledge/` | статьи базы знаний (в репозиторий не попадают — см. выше) |
| `quiz/questions.json` | эталонный файл вопросов викторины; в банк вопросов попадает кнопкой в панели `/quizadm` |
| `seed.db` | заготовка базы для первого запуска |
| `preflight.py` | предполётные проверки: запустится ли бот (их запускают `deploy.sh` и GitHub Actions) |
| `selftest.py` | проверки поведения: правильно ли бот считает (запускаются там же) |
| `deploy.sh`, `deploy-restart.sh` | обновление кода на сервере |
| `watchdog_local.py` | локальный сторож; на хостинге с автоперезапуском не нужен |
| `.claude/` | карта проекта и правила работы для Claude |

## Копии базы

Раз в сутки бот сам делает копию `history.db`: кладёт сжатый файл в `backups/`
(хранятся последние 7) и отправляет его владельцу в личку следом за суточным
отчётом о расходах, а вторым файлом — архив статей базы знаний
(`knowledge-ГГГГ-ММ-ДД_ЧЧ-ММ.tar.gz`). Копия по требованию — кнопка
«💾 Копия базы» в панели «💬 Статистика» (`/adm`) или раздел «🛠 Обслуживание»
на сайте.

Восстановление: распаковать `history-ГГГГ-ММ-ДД_ЧЧ-ММ.db.gz` любым архиватором
и положить получившийся файл на место `history.db` при остановленном боте.

## Проверки перед выкаткой

`python preflight.py` — загрузка всех модулей, сверка моделей с кнопками,
кнопок с обработчиками, таблиц со списком сброса и сборка каждой панели на
временной базе. Отвечает на вопрос «запустится ли бот».

`python selftest.py` — проверки поведения: расчёт денег и прайс, права доступа,
муты, отчёты, сайт и другое. Отвечает на вопрос «правильно ли бот считает».

Обеим не нужны ни сеть, ни ключи, ни боевая база; код возврата 1 означает,
что выкатывать нельзя. `deploy.sh` на сервере гоняет обе при каждом обновлении
(вместе с проверкой синтаксиса и загрузки главных модулей) — не прошло, значит
откат на прежнюю версию. Те же проверки идут в GitHub Actions на каждый push
в `main` и pull request.

⚠️ Сервер сам забирает новый код из `main` раз в 5 минут, дождавшись минуты
тишины в чатах: всё, что попало в `main`, доезжает до людей без участия
человека.

## Требования

Python 3.12 или новее (на сервере 3.12; на 3.10 и 3.11 код сайта не
запускается), зависимости — в `requirements.txt` (все лёгкие).
Боту хватает ~60 МБ оперативной памяти.
