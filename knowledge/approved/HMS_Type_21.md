# HMS Type 21

HMS Type 21 (игровые прозвища: Тайп 21, тип 21) — британский ракетный эсминец («ракетник») VI ранга в War Thunder Mobile, фрегат класса Amazon времён Фолклендов. Универсальный набор: ПКР Exocet, зенитные Sea Cat, 114-мм артустановка и торпеды, плюс РЭБ. Алюминиевые надстройки — живучесть соответствующая.

## Характеристики (ТТХ)

| Характеристика | Значение |
| :--- | :--- |
| **Тип** | Ракетный эсминец (фрегат), Великобритания, Ранг VI |
| **ПКР Exocet (350-мм)** | урон 7360, перезарядка 12 с |
| **ЗУР Sea Cat (190-мм)** | урон 3500, перезарядка 12 с; быстрая ракета против авиации и катеров |
| **Артиллерия** | 114-мм установка в носу — урон 400, перезарядка 2.6 с |
| **Торпеды (324-мм)** | урон 3000, перезарядка 10 с; два трёхтрубных аппарата |
| **РЭБ** | система сброса наведения (15 с) + дымы |
| **Время наведения ракет** | 5 с |
| **Скорость** | 45 км/ч |
| **Время поворота** | 18 с |
| **Экипаж** | 180 человек (минимальный — 30) |

## Сильные и слабые стороны

**Сильные стороны HMS Type 21:**
* ПКР Exocet с коротким КД (12 с) — стабильный поток урона;
* быстрые ЗУР Sea Cat — защита от авиации и добивание лёгких целей;
* 114-мм пушка и торпеды — не беспомощен вблизи;
* РЭБ срывает вражеские ракетные атаки.

**Слабые стороны HMS Type 21:**
* низкая живучесть — лёгкая конструкция не терпит сфокусированного огня;
* умеренная подвижность — не для стремительных рейдов и одиночных прорывов;
* урон Exocet скромнее, чем у Harpoon.

## Тактика и роль в бою

Роль HMS Type 21 — универсальный ракетный корабль ГРУППОВОЙ игры. В одиночку ему не хватает ни скорости, ни живучести, зато в связке с союзниками, прикрывающими от фокусных атак, он выдаёт стабильный поток урона Экзосетами каждые 12 секунд. Держаться за укрытиями и в строю, работать по приоритетным целям, РЭБ включать при первом же захвате. В ближнем бою сочетание пушки и торпед способно удивить зарвавшегося противника.
