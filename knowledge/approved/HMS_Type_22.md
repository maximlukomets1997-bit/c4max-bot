# HMS Type 22

HMS Type 22 (игровые прозвища: Тайп 22, тип 22) — британский ракетный эсминец («ракетник») VI ранга в War Thunder Mobile, фрегат класса Broadsword/Cornwall. Универсал с отличным уроном: ПКР Harpoon, быстрые Sea Wolf (бьют и по кораблям), 114-мм автоматическая пушка, 30-мм зенитный автомат и система перехвата ракет. Торпед нет, брони тоже.

## Характеристики (ТТХ)

| Характеристика | Значение |
| :--- | :--- |
| **Тип** | Ракетный эсминец (фрегат), Великобритания, Ранг VI |
| **ПКР Harpoon (340-мм)** | урон 9500, перезарядка 12 с |
| **ЗУР Sea Wolf (190-мм)** | урон 3500, перезарядка 12 с; применима по надводным целям |
| **Артиллерия** | 114-мм автоматическая пушка в носу — урон 400, перезарядка 1.8 с |
| **ПВО** | 30-мм автомат Oerlikon KCB — урон 46, перезарядка 0.3 с |
| **ПРО** | система перехвата ракет (5 с) |
| **РЭБ** | система сброса наведения + дымы + контрмеры |
| **Торпеды** | нет |
| **Время наведения ракет** | 5 с |
| **Скорость** | 49 км/ч |
| **Время поворота** | 17 с |
| **Экипаж** | 230 человек (минимальный — 30) |

## Сильные и слабые стороны

**Сильные стороны HMS Type 22:**
* Harpoon каждые 12 секунд — высокая плотность главного урона;
* Sea Wolf двойного назначения — быстрый инструмент против авиации и надводных целей;
* 114-мм автоматическая пушка (1.8 с) — лучший темп среди британских «ракетников»;
* ПРО + РЭБ — двойная защита от ракетных залпов;
* скорость 49 км/ч — достаточно для активной игры.

**Слабые стороны HMS Type 22:**
* торпед нет — в упор рассчитывать только на артиллерию;
* брони практически нет, экипаж ограничен — длительные перестрелки фатальны.

## Тактика и роль в бою

Роль HMS Type 22 — универсальный «дамагер» для соло и группы. Играть от укрытий или из-за спин союзников, методично отгружая Harpoon каждые 12 секунд; Sea Wolf добивает повреждённых и снимает авиацию. В ближний бой не лезть — торпед нет, а живучесть низкая: если противник прорвался в упор, работать 114-мм автоматом и отходить под дымами. ПРО и РЭБ позволяют пережить чужой залп — держать их наготове перед выходом из укрытия.
